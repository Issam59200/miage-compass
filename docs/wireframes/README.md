# Wireframes

Maquettes simples (emplacement des éléments, pas le design final) pour l'accueil et le calendrier, en version ordinateur et mobile.

- `accueil.png` : page d'accueil
- `calendrier.png` : page calendrier
- `wireframes.pdf` : les deux pages, à déposer sur Moodle sous le nom `MIAGECOMPASS_MAQUETTE.pdf`

Les autres pages (guide, FAQ, À propos) reprennent le même en-tête et le même pied de page, avec du texte au centre.
